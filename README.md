# Автотест для API Яндекс.Самоката

Проект содержит автотест для проверки получения заказа по его трек-номеру в приложении Яндекс Самокат.

## Что проверяется

Автоматически проверяется получение заказа по его трек-номеру:

Создаётся новый заказ.
Из ответа на создание заказа получаем track.
Выполняется запрос на получение заказа по track.
Проверяется, что сервер возвращает статус-код 200.

## Структура проекта

* `configuration.py` — URL сервера и пути API.

* `data.py` — данные для создания заказа.

* `sender_stand_request.py` — функции для отправки HTTP-запросов.

* `create_order_test.py` — автотест для проверки получения заказа по его трек-номеру

* `.gitignore` — файлы и папки, которые не нужно загружать в Git.

* `README.md` — описание проекта.

## Запуск тестов

1. Создать и активировать виртуальное окружение.

2. Установить необходимые библиотеки:

pip install requests pytest


3. Запустить все тесты:

pytest
